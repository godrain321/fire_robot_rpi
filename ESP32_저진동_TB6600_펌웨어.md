# ESP32 저진동 TB6600 펌웨어

대상 구성:

- ESP32 DevKit V4 / ESP32-WROOM-32E
- TB6600 2개
- 200 full-step/revolution 스테퍼 모터
- TB6600 DIP: 1/8 microstep
- 실제 encoder 없음
- Raspberry Pi USB Serial: `/dev/ttyUSB0`, 115200 baud

현재 실차 시험 결과인 `w=좌회전`, `x=우회전`, `a=전진`, `d=후진`을 보정하기 위해 왼쪽 모터 방향을 반전했다.

```cpp
const bool INVERT_LEFT_DIR = true;
const bool INVERT_RIGHT_DIR = false;
```

이 코드는 출발·감속·방향 전환에 속도 ramp를 적용한다. 단, `STOP`과 500ms watchdog은 안전을 위해 ramp 없이 즉시 정지한다.

## 업로드할 전체 코드

```cpp
#include <AccelStepper.h>
#include <math.h>
#include <stdlib.h>

/*
  ESP32 DevKit V4 / ESP32-WROOM-32E
  Dual TB6600 low-vibration serial motor bridge

  Pi -> ESP32:
    M,<seq>,<left_sps>,<right_sps>
    STOP,<seq>
    PING,<seq>
    ZERO,<seq>
    K,<seq>,<W|X|A|D|S>

  ESP32 -> Pi:
    ACK,<seq>
    STAT,<millis>,<state>,<left_sps>,<right_sps>
    ENC,<millis>,<left_count>,<right_count>
    ERR,<message>

  No physical encoders are required. AccelStepper::currentPosition()
  reports the signed STEP pulses actually generated by this firmware.
*/

// -------------------- Pin mapping --------------------
#define L_STEP 25
#define L_DIR  26
#define L_EN   27

#define R_STEP 14
#define R_DIR  12
#define R_EN   13

// GPIO12 is an ESP32 strapping pin. Keep the current wiring for this test.
// If boot/upload becomes unreliable, move R_DIR to GPIO32 or GPIO33 later.

// -------------------- Direction / enable --------------------
const bool ENABLE_ACTIVE_LOW = true;

// Physical direction correction based on the observed key behavior:
// before: W/X=turn, A/D=forward/reverse
// expected after correction: W/X=forward/reverse, A/D=left/right turn
const bool INVERT_LEFT_DIR  = true;
const bool INVERT_RIGHT_DIR = false;

// -------------------- Motion tuning --------------------
// TB6600 DIP setting: 1/8 microstep
// 200 full steps/rev * 8 = 1600 pulses/rev
const float MAX_STEP_SPEED = 1600.0F;       // Absolute hard limit, step/s
const float DEFAULT_KEY_SPS = 400.0F;       // K,W/X/A/D target, step/s
const float MAX_ACCEL_SPS2 = 500.0F;        // Speed change, step/s^2
const float ZERO_SPEED_EPSILON = 0.5F;      // Treat as zero below this value
const unsigned long RAMP_UPDATE_US = 5000;  // Ramp update every 5 ms

// STOP and watchdog always stop immediately, without ramp.
const unsigned long COMMAND_TIMEOUT_MS = 500;

// -------------------- Status / serial --------------------
const unsigned long STAT_PERIOD_MS = 100;
const unsigned long ENC_PERIOD_MS = 100;
const unsigned long BAUDRATE = 115200;
const size_t MAX_INPUT_LINE = 120;

// -------------------- Motor objects --------------------
AccelStepper leftMotor(AccelStepper::DRIVER, L_STEP, L_DIR);
AccelStepper rightMotor(AccelStepper::DRIVER, R_STEP, R_DIR);

// -------------------- State --------------------
String inputLine;

float targetLeftSps = 0.0F;
float targetRightSps = 0.0F;
float currentLeftSps = 0.0F;
float currentRightSps = 0.0F;

unsigned long lastCommandMs = 0;
unsigned long lastStatMs = 0;
unsigned long lastEncMs = 0;
unsigned long lastRampUs = 0;

bool failsafeActive = false;
String driveState = "BOOT";

// -------------------- Basic helpers --------------------
void setEnable(bool enable) {
  if (ENABLE_ACTIVE_LOW) {
    digitalWrite(L_EN, enable ? LOW : HIGH);
    digitalWrite(R_EN, enable ? LOW : HIGH);
  } else {
    digitalWrite(L_EN, enable ? HIGH : LOW);
    digitalWrite(R_EN, enable ? HIGH : LOW);
  }
}

float clampSps(float value) {
  if (value > MAX_STEP_SPEED) return MAX_STEP_SPEED;
  if (value < -MAX_STEP_SPEED) return -MAX_STEP_SPEED;
  return value;
}

bool isNearZero(float value) {
  return fabsf(value) <= ZERO_SPEED_EPSILON;
}

bool speedsMatch(float current, float target) {
  return fabsf(current - target) <= ZERO_SPEED_EPSILON;
}

float physicalLeftSps(float logicalSps) {
  return INVERT_LEFT_DIR ? -logicalSps : logicalSps;
}

float physicalRightSps(float logicalSps) {
  return INVERT_RIGHT_DIR ? -logicalSps : logicalSps;
}

void applyCurrentSpeeds() {
  leftMotor.setSpeed(physicalLeftSps(currentLeftSps));
  rightMotor.setSpeed(physicalRightSps(currentRightSps));
}

void updateDriveState() {
  if (failsafeActive) {
    driveState = "FAILSAFE";
    return;
  }

  const bool targetStopped =
      isNearZero(targetLeftSps) && isNearZero(targetRightSps);
  const bool currentStopped =
      isNearZero(currentLeftSps) && isNearZero(currentRightSps);

  if (targetStopped && currentStopped) {
    driveState = "STOP";
  } else if (speedsMatch(currentLeftSps, targetLeftSps) &&
             speedsMatch(currentRightSps, targetRightSps)) {
    driveState = "RUN";
  } else {
    driveState = "RAMP";
  }
}

void setTargetSpeeds(float leftSps, float rightSps) {
  targetLeftSps = clampSps(leftSps);
  targetRightSps = clampSps(rightSps);
  failsafeActive = false;
  updateDriveState();
}

void immediateStop(bool failsafe) {
  targetLeftSps = 0.0F;
  targetRightSps = 0.0F;
  currentLeftSps = 0.0F;
  currentRightSps = 0.0F;
  leftMotor.setSpeed(0.0F);
  rightMotor.setSpeed(0.0F);
  failsafeActive = failsafe;
  driveState = failsafe ? "FAILSAFE" : "STOP";
}

// -------------------- Non-blocking speed ramp --------------------
float approachWithoutInstantReverse(
    float current, float target, float maxDelta) {
  if (isNearZero(current)) current = 0.0F;
  if (isNearZero(target)) target = 0.0F;

  // If signs differ, decelerate to exactly zero first. A later update will
  // accelerate in the opposite direction, so DIR never flips at speed.
  if ((current > 0.0F && target < 0.0F) ||
      (current < 0.0F && target > 0.0F)) {
    if (current > 0.0F) {
      current -= maxDelta;
      if (current <= ZERO_SPEED_EPSILON) current = 0.0F;
    } else {
      current += maxDelta;
      if (current >= -ZERO_SPEED_EPSILON) current = 0.0F;
    }
    return current;
  }

  if (current < target) {
    current += maxDelta;
    if (current > target) current = target;
  } else if (current > target) {
    current -= maxDelta;
    if (current < target) current = target;
  }

  if (isNearZero(current) && isNearZero(target)) return 0.0F;
  return current;
}

void updateSpeedRamp() {
  const unsigned long nowUs = micros();
  const unsigned long elapsedUs = nowUs - lastRampUs;
  if (elapsedUs < RAMP_UPDATE_US) return;

  lastRampUs = nowUs;
  float dt = elapsedUs * 0.000001F;

  // Prevent one delayed loop iteration from causing a large speed jump.
  if (dt > 0.05F) dt = 0.05F;

  const float maxDelta = MAX_ACCEL_SPS2 * dt;
  currentLeftSps = approachWithoutInstantReverse(
      currentLeftSps, targetLeftSps, maxDelta);
  currentRightSps = approachWithoutInstantReverse(
      currentRightSps, targetRightSps, maxDelta);

  currentLeftSps = clampSps(currentLeftSps);
  currentRightSps = clampSps(currentRightSps);
  applyCurrentSpeeds();
  updateDriveState();
}

// -------------------- Protocol output --------------------
void sendAck(const String &seq) {
  Serial.print("ACK,");
  Serial.println(seq);
}

void sendErr(const String &message) {
  Serial.print("ERR,");
  Serial.println(message);
}

void sendStat() {
  Serial.print("STAT,");
  Serial.print(millis());
  Serial.print(',');
  Serial.print(driveState);
  Serial.print(',');
  Serial.print(currentLeftSps, 1);
  Serial.print(',');
  Serial.println(currentRightSps, 1);
}

long logicalLeftCount() {
  const long physicalCount = leftMotor.currentPosition();
  return INVERT_LEFT_DIR ? -physicalCount : physicalCount;
}

long logicalRightCount() {
  const long physicalCount = rightMotor.currentPosition();
  return INVERT_RIGHT_DIR ? -physicalCount : physicalCount;
}

void sendEnc() {
  Serial.print("ENC,");
  Serial.print(millis());
  Serial.print(',');
  Serial.print(logicalLeftCount());
  Serial.print(',');
  Serial.println(logicalRightCount());
}

void resetCounts() {
  // AccelStepper::setCurrentPosition() also sets its internal speed to zero.
  leftMotor.setCurrentPosition(0);
  rightMotor.setCurrentPosition(0);
  applyCurrentSpeeds();
}

// -------------------- Strict parsing --------------------
int splitCsv(String line, String parts[], int maxParts) {
  int count = 0;
  int start = 0;
  line.trim();

  while (count < maxParts) {
    const int comma = line.indexOf(',', start);
    if (comma == -1) {
      parts[count++] = line.substring(start);
      break;
    }
    parts[count++] = line.substring(start, comma);
    start = comma + 1;
  }

  // More fields than maxParts is an invalid line.
  if (count == maxParts && line.indexOf(',', start) != -1) return -1;

  for (int index = 0; index < count; ++index) parts[index].trim();
  return count;
}

bool parseStrictFloat(const String &text, float &value) {
  if (text.length() == 0 || text.length() >= 32) return false;

  char buffer[32];
  text.toCharArray(buffer, sizeof(buffer));
  char *endPointer = nullptr;
  const float parsed = strtof(buffer, &endPointer);

  if (endPointer == buffer || *endPointer != '\0' || !isfinite(parsed)) {
    return false;
  }

  value = parsed;
  return true;
}

bool validSeq(const String &seq) {
  return seq.length() > 0;
}

// -------------------- Command handlers --------------------
void handleKeyCommand(const String &seq, String key) {
  if (!validSeq(seq)) {
    sendErr("BAD_SEQ");
    return;
  }

  key.toUpperCase();
  if (key == "W") {
    setTargetSpeeds(DEFAULT_KEY_SPS, DEFAULT_KEY_SPS);
  } else if (key == "X") {
    setTargetSpeeds(-DEFAULT_KEY_SPS, -DEFAULT_KEY_SPS);
  } else if (key == "A") {
    setTargetSpeeds(-DEFAULT_KEY_SPS, DEFAULT_KEY_SPS);
  } else if (key == "D") {
    setTargetSpeeds(DEFAULT_KEY_SPS, -DEFAULT_KEY_SPS);
  } else if (key == "S") {
    immediateStop(false);
  } else {
    sendErr("UNKNOWN_KEY_" + key);
    return;
  }

  lastCommandMs = millis();
  sendAck(seq);
}

void handleLine(String line) {
  line.trim();
  if (line.length() == 0) return;

  String parts[6];
  const int partCount = splitCsv(line, parts, 6);
  if (partCount <= 0) {
    sendErr("BAD_FORMAT");
    return;
  }

  String command = parts[0];
  command.toUpperCase();

  if (command == "M") {
    if (partCount != 4) {
      sendErr("BAD_M_FORMAT");
      return;
    }
    if (!validSeq(parts[1])) {
      sendErr("BAD_SEQ");
      return;
    }

    float leftSps = 0.0F;
    float rightSps = 0.0F;
    if (!parseStrictFloat(parts[2], leftSps) ||
        !parseStrictFloat(parts[3], rightSps)) {
      sendErr("BAD_M_VALUE");
      return;
    }

    setTargetSpeeds(leftSps, rightSps);
    lastCommandMs = millis();
    sendAck(parts[1]);
    return;
  }

  if (command == "STOP") {
    if (partCount != 2 || !validSeq(parts[1])) {
      sendErr("BAD_STOP_FORMAT");
      return;
    }
    immediateStop(false);
    lastCommandMs = millis();
    sendAck(parts[1]);
    return;
  }

  if (command == "PING") {
    if (partCount != 2 || !validSeq(parts[1])) {
      sendErr("BAD_PING_FORMAT");
      return;
    }
    sendAck(parts[1]);
    sendStat();
    sendEnc();
    return;
  }

  if (command == "ZERO") {
    if (partCount != 2 || !validSeq(parts[1])) {
      sendErr("BAD_ZERO_FORMAT");
      return;
    }
    resetCounts();
    sendAck(parts[1]);
    return;
  }

  if (command == "K") {
    if (partCount != 3) {
      sendErr("BAD_K_FORMAT");
      return;
    }
    handleKeyCommand(parts[1], parts[2]);
    return;
  }

  sendErr("UNKNOWN_CMD_" + command);
}

void readSerialLines() {
  while (Serial.available() > 0) {
    const char character = static_cast<char>(Serial.read());

    // Accept CR, LF and CRLF. Ignore empty terminators.
    if (character == '\r' || character == '\n') {
      if (inputLine.length() > 0) {
        handleLine(inputLine);
        inputLine = "";
      }
      continue;
    }

    // Ignore non-printable bytes rather than adding them to a command.
    if (character < 32 || character > 126) continue;

    if (inputLine.length() >= MAX_INPUT_LINE) {
      inputLine = "";
      sendErr("LINE_TOO_LONG");
      continue;
    }

    inputLine += character;
  }
}

// -------------------- Arduino setup / loop --------------------
void setup() {
  Serial.begin(BAUDRATE);
  inputLine.reserve(MAX_INPUT_LINE);

  pinMode(L_EN, OUTPUT);
  pinMode(R_EN, OUTPUT);
  setEnable(true);

  leftMotor.setMaxSpeed(MAX_STEP_SPEED);
  leftMotor.setMinPulseWidth(5);
  rightMotor.setMaxSpeed(MAX_STEP_SPEED);
  rightMotor.setMinPulseWidth(5);

  targetLeftSps = 0.0F;
  targetRightSps = 0.0F;
  currentLeftSps = 0.0F;
  currentRightSps = 0.0F;
  leftMotor.setCurrentPosition(0);
  rightMotor.setCurrentPosition(0);
  immediateStop(false);

  const unsigned long nowMs = millis();
  lastCommandMs = nowMs;
  lastStatMs = nowMs;
  lastEncMs = nowMs;
  lastRampUs = micros();
  driveState = "READY";

  Serial.println("STAT,0,READY,0,0");
  Serial.println("ENC,0,0,0");
}

void loop() {
  // runSpeed() must be called as often as possible. Each call generates at
  // most one due STEP pulse and updates currentPosition().
  leftMotor.runSpeed();
  rightMotor.runSpeed();

  readSerialLines();

  const unsigned long nowMs = millis();
  if ((nowMs - lastCommandMs) > COMMAND_TIMEOUT_MS &&
      (!isNearZero(targetLeftSps) || !isNearZero(targetRightSps) ||
       !isNearZero(currentLeftSps) || !isNearZero(currentRightSps))) {
    immediateStop(true);
    Serial.println("ERR,COMMAND_TIMEOUT_STOP");
  }

  updateSpeedRamp();

  // Call again after serial/ramp processing to minimize STEP scheduling gaps.
  leftMotor.runSpeed();
  rightMotor.runSpeed();

  if ((nowMs - lastStatMs) >= STAT_PERIOD_MS) {
    lastStatMs = nowMs;
    sendStat();
  }

  if ((nowMs - lastEncMs) >= ENC_PERIOD_MS) {
    lastEncMs = nowMs;
    sendEnc();
  }
}
```

## 주요 조절값

속도가 부족하면 한 번에 크게 올리지 말고 다음 순서로 조정한다.

```cpp
const float DEFAULT_KEY_SPS = 400.0F;
const float MAX_ACCEL_SPS2 = 500.0F;
const float MAX_STEP_SPEED = 1600.0F;
```

- `DEFAULT_KEY_SPS`: `K,W/X/A/D` 수동 명령의 목표 속도
- `MAX_ACCEL_SPS2`: 값이 작을수록 부드럽지만 목표 속도 도달이 느림
- `MAX_STEP_SPEED`: 어떤 명령도 넘을 수 없는 절대 상한
- ROS2 `w/x/a/d`는 `DEFAULT_KEY_SPS`가 아니라 Raspberry Pi가 계산한 `M` 속도를 사용함

초기 권장 조정 범위:

```text
DEFAULT_KEY_SPS: 200~500 step/s
MAX_ACCEL_SPS2: 300~800 step/s²
MAX_STEP_SPEED: 800~1600 step/s
```

## 1/8 microstep 동기화

TB6600 DIP를 1/8로 변경한 다음 Raspberry Pi 설정도 반드시 다음과 같이 맞춰야 한다.

```yaml
cmdvel_to_esp32_serial:
  ros__parameters:
    microsteps: 8

step_count_to_odom:
  ros__parameters:
    microsteps: 8
```

설정 파일:

```text
~/fire_robot_rpi/inno_jazzy_ws/src/inno_drive_bridge/config/drive_params.yaml
```

1/8 DIP인데 ROS가 1/2로 남아 있으면 실제 속도와 odometry가 맞지 않는다.

## 업로드 및 최초 시험

1. 모터 배터리를 끈다.
2. ROS2, picocom, Python serial 검사기를 모두 종료한다.
3. 위 코드를 Arduino IDE에서 ESP32에 업로드한다.
4. `PING,1 → ACK,1`을 확인한다.
5. `STOP,2 → ACK,2`를 확인한다.
6. 바퀴를 공중에 띄운다.
7. 모터 배터리를 켠다.
8. 먼저 `s`를 입력한다.
9. `w`를 짧게 누른 후 즉시 `s`를 누른다.
10. `x`, `a`, `d`도 각각 짧게 시험하고 매번 `s`로 정지한다.
11. 이상 진동이나 방향 오류가 있으면 즉시 모터 배터리를 끈다.

코드 ramp로 완화할 수 있는 것은 급출발, 급감속, 즉시 방향 반전이다. 코일 쌍 오류, TB6600 전류 DIP 오류, 전원 부족, 한 상 단선, 기계적 걸림이나 공진은 펌웨어만으로 해결할 수 없다.
